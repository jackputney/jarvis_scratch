## How to write a feature doc

Each doc should cover:

1. **What it does** — one sentence
2. **Files involved** — list key files with notes
3. **How it works** — brief explanation
4. **Platform notes** — Mac vs Windows differences
5. **Gotchas** — what to watch out for
6. **How to test** — step-by-step or curl commands
